# AVALON Mods

[AVALON Launcher](https://github.com/Daehyun10/Avalon-Launcher)에서 사용하는 모드와 실행 프로필입니다.

## 지원 환경

- Minecraft 1.18.2 / Forge 40.2.0
- Java 17

## 포함 모드

**Enhance System**은 무기 강화와 전투 스킬을 추가합니다. 런처의 설정 → Mods에서 켜고 끌 수 있으며, 서버와 클라이언트에는 같은 버전을 설치해야 합니다.

크리에이티브 보관함의 **강화 모드 무기** 탭에서 추가 무기와 강화 가능한 기본 무기·도구를 찾을 수 있습니다. 레이피어 아이콘이 있는 탭이며, 페이지 화살표로 이동할 수 있습니다.

강화 창과 능력 선택 창은 GUI 배율과 화면 크기에 맞춰 조절됩니다.

**AVALON Client**는 게임 창 제목과 아이콘을 설정하는 클라이언트 모드입니다. 서버에는 설치하지 않습니다.

Discord 활동 표시를 사용하려면 Discord 데스크톱 앱을 실행해 두세요. 자세한 내용은 [Discord 이용 안내](discord-setup.md)를 참고하세요.
